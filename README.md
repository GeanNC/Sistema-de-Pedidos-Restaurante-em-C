# Sistema de Pedidos de Restaurante — C

Aplicação em linguagem **C** que simula um sistema de pedidos de restaurante em terminal, com menus interativos, cálculo de total e exibição de resumo detalhado do pedido.

# Funcionalidades
- Menu principal com seções de produtos (massas, carnes, bebidas, sobremesas, etc.)
- Submenus dinâmicos com códigos e preços
- Cálculo automático do total do pedido
- Exibição detalhada do resumo da compra
- Opção para finalizar ou reiniciar o pedido

# Tecnologias
- Linguagem C  
- Biblioteca padrão (`stdio`, `stdlib`, `ctype`, `time`, `locale`)
- Interface em terminal
